# Current Milestone: UI and Playability Pass

## Objective

Make the existing game comfortable and immersive enough for a real playtest.

Do not add gameplay systems.

## Approved work

- Improve story readability
- Improve page spacing and typography
- Create a modern story-first layout
- Make secondary information collapsible
- Improve character creation answer layout
- Improve action button hierarchy
- Improve NPC, travel, and location cards
- Improve responsive/mobile layout
- Add subtle transitions
- Fix genuine navigation and usability blockers

## Forbidden work

- No gameplay changes
- No database changes
- No progression changes
- No new catalogs
- No new systems
- No new JavaScript framework
- No dependency upgrade unless specifically approved
- No conversion away from the current server-rendered architecture

## Success criteria

- Story is the visual focus.
- Character information is not permanently overwhelming.
- Character creation choices align clearly with their questions.
- Primary actions are visually obvious.
- Secondary systems remain available but unobtrusive.
- Existing tests pass.
- The game remains playable from character creation through the current living loop.
