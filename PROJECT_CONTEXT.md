# Cultivation RPG Project Context

This is a deterministic, data-driven cultivation RPG.

## Locked philosophy

- Purpose comes from Aspirations.
- Curiosity comes from authored Events.
- Identity describes existing facts.
- Gameplay systems write facts.
- Aspirations read facts.
- Identity describes facts.
- AI provides voice and presentation, never mechanical truth.

## Completed foundations

- Character creation and opening story
- Cultivation sessions and breakthroughs
- Modifier Framework
- Techniques
- Spiritual Roots
- Alchemy
- World packs and locations
- Travel and location actions
- Event Engine
- NPC catalogs and persistent state
- NPC interactions
- Sect membership and standing
- Authored NPC requirement and reward framework
- Aspiration system
- Phase 11a and 11b living-loop content

## Current development emphasis

The engine architecture is largely complete.

Current work should prioritize:

- UI usability
- authored content
- player-facing clarity
- playtesting
- memorable NPCs
- duties and exploration
- event density
- meaningful aspiration paths

Prefer improving existing systems over inventing new ones.

## Current quality requirements

- Preserve save compatibility.
- Preserve all existing tests.
- Keep the game playable after every task.
- Stop after bounded tasks for review.
